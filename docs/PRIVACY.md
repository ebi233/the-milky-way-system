# 隐私与公开发布范围

公开仓库只收录代码、通用测试、配置示例和项目文档。不会把生产目录直接作为 Git 工作树上传。

## 不发布

- QQ 号码、内部会话标识、服务器真实地址、SSH 密钥、管理令牌、API 密钥、Cookie、扫码数据及登录数据库。
- 私聊/群聊原文、长期记忆条目、关系档案、表达语料、私人原人格及自主版本内容。
- 用户图片、生成候选及成图、语音样本、浏览器 profile、缓存、生产日志、历史备份。
- 模型权重、QQ/DSH 二进制、node_modules、实验 Inspector/eval 引导器。

代码中的 `10001` / `10002` / `10003`、`20001` / `20002` 和 `session-example` 是虚构示例。导出的群人格不包含泡泡的具体私人关系。用于测试的消息与账号来自隔离夹具，不依赖真实聊天基线。

## 保留的保护机制

消息正文、昵称或引用不能授予身份。主私聊、访客、群与维护来源分别处理；群账号也不能因此读取私聊资料。记忆和媒体都需要对应来源与会话。

服务绑定回环地址、专用鉴权、限制请求体和图片大小。请求结果未知不自动重发；图片 ready 与发送回执、用户确认分别记录。群静默独立于普通来信回应。

## 发布检查

`tools/check_publication.py` 检查禁入路径、私钥/常见 token 格式、相对链接、配置 JSON 和语言语法。上传前另有仅保存在本机的真实标识扫描；真实标识列表本身不会放进公开仓库。

自动扫描不能证明绝无隐私风险；因此采用代码白名单导出并人工检查敏感默认值，避免依赖 .gitignore 去掩盖已经被纳入的私人文件。后续提交也应先检查 Git 暂存内容。
